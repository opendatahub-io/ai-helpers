# odh-rpm

RPM build failure analysis and non-Red Hat RPM detection

## Install

```text
/plugin marketplace add opendatahub-io/ai-helpers
/plugin install odh-rpm@odh-ai-helpers
```

## Skills

- **non-redhat-rpms** — Use this skill to identify non-Red Hat RPM packages installed in container images or on the local machine.
- **rpm-examine** — Analyze RPM build.log failures.
