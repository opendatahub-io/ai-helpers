# odh-modules

ODH module operator scaffolding, migration, and compliance checks

## Install

```text
/plugin marketplace add opendatahub-io/ai-helpers
/plugin install odh-modules@odh-ai-helpers
```

## Skills

- **module-compliance** — Check an ODH module operator repository for contract violations against the platform onboarding guide.
- **module-migrate** — Read existing in-tree ODH operator component code and produce a step-by-step extraction checklist for migrating it to a standalone module.
- **module-scaffold** — Given a component name, generate a complete standalone ODH module operator repository.
