# odh-google-workspace

Gmail, Google Calendar, Docs, and Drive integration

## Install

```text
/plugin marketplace add opendatahub-io/ai-helpers
/plugin install odh-google-workspace@odh-ai-helpers
```

## Skills

- **email-meeting-summary** — Use when the user wants to summarize a Google Meet meeting and send the summary by email.
- **gmail-draft** — Use this skill to compose a Gmail draft from text content in the conversation.
- **google-workspace** — Fetch and query data from Google Workspace using the gws CLI — Gmail, Calendar, Docs, Sheets, Slides, and Drive.
