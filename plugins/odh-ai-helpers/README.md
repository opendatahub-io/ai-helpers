# odh-ai-helpers

[DEPRECATED] Backwards-compatibility bundle re-exporting every ODH AI Helpers skill under the original odh-ai-helpers:* names. Install the individual odh-* plugins you need instead; this bundle is removed after the migration window.

This umbrella re-exports **every** ODH AI Helpers skill under the legacy
`odh-ai-helpers:*` names so existing workflows keep working after the split.
It is **deprecated** and will be removed after the migration window.

**Migrate:** install the individual `odh-*` plugins you use (browse with `/plugin`) and disable this one.
