# odh-team

Team weekly reports, engineer activity snapshots, and delivery postmortems

## Install

```text
/plugin marketplace add opendatahub-io/ai-helpers
/plugin install odh-team@odh-ai-helpers
```

## Skills

- **create-delivery-postmortem** — Use when a release delay, missed deadline, or delivery incident needs a structured post-mortem.
- **engineer-snapshot** — Generate an engineer activity snapshot showing active JIRA issues with days open, blocked work, upstream PRs awaiting review, recently merged PRs, and open act….
- **team-weekly-report** — Generate a weekly team status report combining JIRA and GitHub data.
