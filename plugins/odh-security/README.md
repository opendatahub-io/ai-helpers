# odh-security

Supply-chain security alerting and OCI image CVE comparison

## Install

```text
/plugin marketplace add opendatahub-io/ai-helpers
/plugin install odh-security@odh-ai-helpers
```

## Skills

- **oci-cve-checker** — Use this skill to compare CVE vulnerabilities between two OCI container images and generate reports showing fixed and new CVEs.
- **security-alert** — Use this skill to filter a pre-fetched set of Hacker News stories down to those that report supply-chain security threats relevant to the Red Hat / RHEL ecosys….
