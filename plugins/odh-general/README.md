# odh-general

General-purpose helpers and learning mode

## Install

```text
/plugin marketplace add opendatahub-io/ai-helpers
/plugin install odh-general@odh-ai-helpers
```

## Skills

- **learning-mode** — Hands-on mentoring: the agent scaffolds work, then pauses so the engineer writes small, meaningful code (roughly 5–15 lines) for practice.
